# Per-dataset figures (D1-D8)

The manuscript / ISMB-deck Results figures, one file per dataset, same plotting code and style as the
pooled originals (only the data is restricted to a single dataset). Generated by the section
"Per-dataset figures, D1-D8" at the end of `notebooks/accuracy_fixed_executed.ipynb`
(`pd_`-prefixed, self-contained; validated against the pooled numbers and the Fig 7 supplementary tally).

Every file is a single standalone chart. The pooled originals combine some of these into one
multi-panel image (Fig 3b: Class I | Class II side by side; Fig 5: linear | log side by side) --
here each panel is its own file, not a composite.

| file (per `D1` ... `D8` folder) | pooled original | ISMB slide |
|---|---|---|
| `01_miscalled_distribution_by_locus_D#` | Fig 6b | Class II loci are most commonly miscalled |
| `02_number_of_miscalled_alleles_by_locus_D#` | Fig 6a | Number of miscalled HLA alleles by locus |
| `03_top20_most_frequently_miscalled_alleles_D#` | Fig 7 | Top 20 most-frequently miscalled alleles |
| `04a_2field_accuracy_locus_heatmap_linear_D#` | Fig 5 (linear panel) | 2-field accuracy |
| `04b_2field_accuracy_locus_heatmap_log_D#` | Fig 5 (log panel) | 2-field accuracy |
| `05a_classI_accuracy_1_and_2field_D#` | Fig 3b (Class I panel) | 1- and 2-field accuracy |
| `05b_classII_accuracy_1_and_2field_D#` | Fig 3b (Class II panel) | 1- and 2-field accuracy |
| `06_bulk_accuracy_1_and_2field_D#` | Fig 3a | (manuscript Fig 3a) |

Not per-dataset by nature: ancestry (Fig 9-11, D1 only), CPU/RAM (Fig 12), read length (Fig 8).

Reading notes: tools with nothing scorable on a dataset are omitted and named in the footnote; `*` = predictions
for only part of the samples; a tool that ran but made only no-calls is a real 0%. `05a`/`05b` sort each panel
independently by its own 2-field accuracy (the pooled Fig 3b has its Class I panel flipped relative to the tool
labels -- see KNOWN_BUGS.md; not an issue here since each class is its own chart).
Numbers behind the figures: `results/per_dataset_accuracy.csv`, `results/per_dataset_counts_by_tool_locus.csv`.
