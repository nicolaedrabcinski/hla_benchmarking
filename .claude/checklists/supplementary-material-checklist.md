# Checklist: Supplementary Material

## Content Confirmation
- [ ] Exact contents requested by PI/co-authors confirmed (this project has an
      open, unresolved item: "Build supplementary table — per Ram/Serghei
      request; confirm exact contents needed" — do not guess scope)
- [ ] Supplementary figures distinguished explicitly from main-text figures
- [ ] Per-dataset breakdowns included where the main text only shows pooled
      results (e.g., Figure S1: accuracy for each dataset individually, per the
      manuscript's current Supplementary Figures section)

## Data Provenance
- [ ] Every supplementary table/figure traces to a specific, current
      `results_summary.md` source or a documented sub-analysis
- [ ] Supplementary novel-allele analysis is split per-dataset as requested
      (dataset-specific vs. universal novel alleles — a currently open BACKLOG
      item)

## Consistency With Main Text
- [ ] No contradiction between a supplementary number and its main-text
      counterpart
- [ ] Supplementary methods detail (if any) doesn't contradict the main Methods
      section's scoring description

## Formatting
- [ ] Stable, agreed identifiers used (Table S1, Figure S1, etc.) — confirmed
      before finalizing, not assigned ad hoc
- [ ] Figure/table numbering cross-referenced correctly from main text

## Sign-off
- [ ] scientific-writer confirms every supplementary number sourced
- [ ] statistics-reviewer confirms any supplementary statistic
- [ ] Human confirms scope matches what was actually requested
